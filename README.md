## `$ cat ./engineering-principles.md`

```text
01. Prefer understanding over memorization.

02. Prefer explicit systems over implicit assumptions.

03. Prefer reproducibility over "works on my machine".

04. Prefer observability over guessing.

05. Prefer automation over repetitive manual work.

06. Prefer small feedback loops over giant releases.

07. Prefer documenting the decision, not only the result.

08. Prefer domain boundaries before premature abstractions.

09. Prefer measuring production behavior over trusting local intuition.

10. If something is confusing:
        stop
        inspect
        reproduce
        isolate
        explain
        then fix
```
